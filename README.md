# Text Editor

A console-based **Text Editor** developed in **C** that provides basic text editing capabilities through a command-line interface. The application supports text insertion, deletion, cursor navigation, search, and undo/redo operations using efficient data structures such as linked lists and stacks.

## Features
- Create and edit text
- Insert and delete characters
- Cursor navigation
- Search text
- Undo and Redo operations
- Save and load files
- Command-line based interface

## Technologies Used
- Advanced C
- Linked Lists
- Stacks
- File Handling
- Structures
- Pointers
- String Manipulation
- Makefile

## Concepts Covered
- Data Structures
- Linked List Operations
- Stack Implementation
- File Processing
- Cursor Management
- Modular Programming

## How to Compile

```bash
make
```

## How to Run

```bash
./text_editor
```

## Project Objective

The objective of this project is to implement a simple text editor using linked lists and stacks, demonstrating concepts of data structures, file handling, cursor management, and undo/redo functionality in C.
